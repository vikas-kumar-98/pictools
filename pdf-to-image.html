Available Output Formats

📸 JPG

Best for photographs and general use. Smaller file size with good quality. Ideal for web and sharing.

🖼️ PNG

Best for graphics with text, logos, and images requiring transparency. Lossless quality with larger file size.

📊 High Quality

Both formats offer adjustable quality settings. Choose higher quality for sharp text and details.

JPG vs PNG for PDF Export

📸 JPG Export

Best for PDFs with photographs, gradients, and complex images. Smaller file size with adjustable compression. Ideal for web and social media sharing.

🖼️ PNG Export

Best for PDFs with text, logos, diagrams, and images requiring transparency. Lossless quality ensures sharp text and clean edges. Larger file size.

Choose JPG for photo-heavy PDFs and smaller file sizes. Choose PNG for documents with text, graphics, or when you need transparency support.
